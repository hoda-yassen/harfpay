# سيرفر منصة حرف

باكند حقيقي (Node.js + قاعدة بيانات SQLite محلية) يفعّل: تسجيل حساب حقيقي، تسجيل الدخول، متابعة الكتّاب (محفوظة فعليًا)، وعدّاد مشاهدات حقيقي للمقالات.

## التشغيل لأول مرة

```bash
cd server
npm install
npm start
```

هيظهر لك: `Harf server running at http://localhost:3000`

## مهم جدًا

بعد تشغيل السيرفر، افتحي الموقع من الرابط:

```
http://localhost:3000/harf-website.html
```

**مش** بفتح ملف `harf-website.html` مباشرة بدبل كليك — لو فتحتيه كملف عادي (`file://`)، هيشتغل الموقع بشكل طبيعي لكن تسجيل الدخول والمتابعة هيرجعوا للوضع التجريبي القديم (محفوظ في المتصفح بس) لأنه مفيش سيرفر يرد على الطلبات.

## قاعدة البيانات

بتتخزن في ملف `server/harf.db` (يتولد أوتوماتيك أول مرة). فيها ٤ حسابات كتّاب تجريبية جاهزة (بنفس أسماء الكتّاب الموجودين في الموقع) بكلمة مرور تجريبية `demo12345` لو حبيتي تجربي تسجيل الدخول بحساب موجود:

- mariam@harf.demo
- ahmed@harf.demo
- sara@harf.demo
- noureddine@harf.demo

لو عايزة تبدئي من الصفر، امسحي ملف `harf.db` وشغّلي السيرفر تاني.

## اللي شغال دلوقتي فعليًا

- تسجيل حساب جديد / تسجيل دخول (بيانات محفوظة في قاعدة بيانات حقيقية، كلمة المرور مشفّرة).
- متابعة/إلغاء متابعة كاتب — محفوظة في قاعدة البيانات وتزيد/تنقص عدد المتابعين فعليًا.
- عداد مشاهدات المقالات بيزيد فعليًا مع كل قراءة.

## اللي لسه محتاج شغل

- نشر مقال جديد من الموقع نفسه (حاليًا المقالات الأربعة مكتوبة كملفات HTML ثابتة، وربطها بقاعدة البيانات للعرض فقط).
- صفحة تحكم/محفظة أرباح حقيقية.
- رفع الموقع على سيرفر حقيقي (استضافة) بدل التشغيل المحلي على جهازك فقط — قاعدة البيانات هنا SQLite للتطوير السريع، ولو حبيتي نشر فعلي على استضافة بعدد كبير من الزوار يُفضّل الانتقال لـ MySQL حسب `harf-database-schema.sql` الأصلي.
